# Questions, answered

**Is this really 24 hours?** Yes — the pipeline (framework choice, IA, content restructure, API reference, CI/CD, checklist) fits inside one working day. The second site for the same team takes half a day.

**Docusaurus or MkDocs — which one?** React stack or need versioning? Docusaurus. Python stack or speed? MkDocs Material. We pick by your stack, not by our preference.

**Can you migrate my existing docs?** That's where we earn the fee — buried Markdown restructured into the sidebar, every relative link fixed, zero content lost.

**What about the API reference?** Auto-generated from your OpenAPI spec — hand-written API docs rot; generated ones don't.

**Hosting costs?** Zero. GitHub Pages or Netlify free tier handles it. You own the repo.

**What if I want updates later?** The repo is yours with CI/CD wired — future edits are one Markdown commit away.
