# Setup guide (sample quickstart)

## Install
```bash
pip install your-package
```

## First run
```bash
your-package init --project my-app
your-package serve --port 8080
```

## Configure
Create `my-app.yml`:
```yaml
project: my-app
api_version: v1
```
